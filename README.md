## 🏗️ Systems I've Shipped

### 🛡️ [SmartID Risk — Explainable AI Risk Engine](https://github.com/sathvikagudise/SmartID-Risk)
> *Python, PyTorch, FastAPI*
> Engineered a deterministic policy engine with an explicit evidence abstraction layer (`AVAILABLE / FAILED / UNKNOWN`). When an experimental ResNet-18 forgery model showed a severe generalization gap (0.43 unseen AUC), I intentionally excluded it from the pipeline to prevent unsafe deployment. The system knows when to say **"insufficient evidence."**

### 🧠 [SkillForge — RAG Learning Platform](https://github.com/sathvikagudise/SkillForge)
> *Python, FastAPI, FAISS, Gemini*
> Multi-provider LLM routing (Ollama, DeepSeek, Gemini) with semantic retrieval. Implemented spaced-repetition flashcards, custom quizzes, and interactive knowledge graphs.

### ♿ [AccessGuard — Accessibility Audit Platform](https://github.com/sathvikagudise/AccessGuard)
> *Python, FastAPI, BeautifulSoup, Vanilla JS*
> Built a full-stack auditing platform that inspects live websites for WCAG violations, generates context-aware HTML remediation guidance, computes accessibility scores, and tracks audit history. Deployed the stateless FastAPI backend on Render and the frontend on Vercel.

### 🌪️ [CrisisMind — Multimodal Disaster Assessment](https://github.com/sathvikagudise/CrisisMind)
> *Python, PyTorch, FastAPI, React*
> Architected a multimodal deep-learning pipeline that assesses disaster severity from social-media images and text. Developed the FastAPI inference server and a React analytics dashboard to visualize prediction metrics and Grad-CAM explainability.

### 📊 [CardioRisk AI — Stacking Ensemble](https://github.com/sathvikagudise/CardioRisk-AI)
> *Python, XGBoost, SHAP, Streamlit*
> Built a stacking ensemble (LR, SVM, RF, XGBoost) for heart disease prediction, optimizing thresholds to achieve **99% recall**. Integrated SHAP waterfall plots to provide transparent, actionable clinical recommendations.

### 🕸️ [CollabGraph — Graph Analytics](https://github.com/sathvikagudise/collabgraph)
> *Python, NetworkX, Streamlit, PyVis*
> Developed a NetworkX-based backend to compute degree/betweenness centrality and Louvain community detection. Implemented a Jaccard-coefficient recommendation engine to suggest potential collaborators.
